# Fisk Worlds · Sala

Instalador do Fisk Worlds (o Bosque) para os computadores das escolas Fisk Personalizado (Windows 10 e 11).
Funciona sem internet; o progresso de cada aluno fica no computador e vai para o Portal do Aluno quando a internet volta.

Baixar: [Fisk-Worlds-Sala.exe](https://github.com/Pedro-Fisk/fisk-worlds-sala/releases/latest/download/Fisk-Worlds-Sala.exe)

Na instalação o Windows avisa "O Windows protegeu o computador": clique em **Mais informações** e depois em **Executar assim mesmo**.
